文档

这里介绍的是 Wu 特有的内容。Wu 和 Zed 共用编辑器核心，所以设置、快捷键、语言、扩展、任务、调试和远程开发这些内容，Zed 文档同样适用于 Wu。

开始使用

在 macOS 和 Linux 上，在终端里运行 curl -fsSL https://wu.dstrml.org/install.sh | sh。也可以下载对应平台的 Wu，然后按照安装指南操作。

命令行wu
设置（macOS、Linux）~/.config/wu
设置（Windows）%APPDATA%\Wu
应用数据（macOS）~/Library/Application Support/Wu
项目设置.wu/

智能体对话

在 Wu 里和 Claude Code、Codex 或 OpenCode 对话。它用的是你已经安装并登录的命令行工具，所以不需要 API 密钥，也不需要 Wu 账号。

  • 开始对话：点击活动栏里的智能体图标。用“继续已保存的对话”可以接着在终端里开始的对话继续。
  • 输入 / 使用命令，@ 提及文件，$ 使用技能。粘贴或拖入图片即可附加。
  • 智能体工作时也能发送：你的消息会排队等待。你可以编辑它，或者用它来引导当前这一轮。
  • 听写：按 Cmd-D（Windows 和 Linux 上是 Ctrl-D）。它在你的电脑上本地运行，需要 Apple 芯片的 macOS 14 或更高版本、Linux 或 Windows。
  • 模型选择器用来设置模型、推理强度和权限。旁边的圆环显示上下文和套餐用量。
  • 对话可以置顶、分叉和重命名。子智能体会在自己的标签页里打开。

通知、自动压缩、Claude in Chrome、隐藏智能体以及关闭智能体对话，都在设置的“智能体对话”页面里。

工作区

  • 侧边的活动栏用来切换项目、Git、大纲、搜索、调试和智能体面板。面板默认停靠在左侧，activity_bar.icon_size 用来设置图标大小。
  • 编辑器和终端标签栏里的 + 按钮位于最后一个标签页之后，点击直接新建文件或终端，不弹出菜单。
  • Cmd-W / Ctrl-W 只关闭编辑器标签页，不会关闭侧边面板。

扩展

Wu 从 Zed 扩展商店安装扩展，不用做任何修改就能在 Wu 里使用。

隐私

Wu 没有账号，没有遥测，也没有崩溃报告。它从不把你的使用数据发送到任何地方。智能体对话只和你所用工具背后的服务商通信。

不包含的功能

  • 协作：频道、通话、屏幕共享和共享项目。
  • Vim 和 Helix 模式。
  • 开发容器。
  • REPL 和日记。

如果 Zed 文档里的某个设置或快捷键属于这些功能，它在 Wu 里不起作用。

从 Zed 迁移

Wu 和 Zed 可以同时安装。它们的设置是分开的，如果想让两边设置一样，把 settings.json 和 keymap.json 从 ~/.config/zed 复制到 ~/.config/wu 就行。

Raycast

在 macOS 上，安装 Raycast 的 Wu 扩展，就能在 Raycast 里打开最近的项目、新窗口和设置。

许可证
